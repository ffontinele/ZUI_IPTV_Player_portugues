# 🎬 ZUI IPTV Player (Português)

Player IPTV completo para LG webOS com suporte a M3U, Xtream e Cloud Sync.

## ✨ Funcionalidades

- 🇧🇷 Interface 100% em Português
- 📺 TV ao Vivo com EPG
- 🎬 Filmes (VOD) com posters
- 📺 Séries com temporadas e episódios
- ☁️ Cloud Sync via Supabase
- 📱 QR Code para configurar
- 🎨 Visual padronizado (amarelo + preto)

## 🚀 Instalação

```bash
git clone https://github.com/ffontinele/ZUI_IPTV_Player_portugues.git
cd ZUI_IPTV_Player_portugues
npm install
npm run build
ares-package dist
```
